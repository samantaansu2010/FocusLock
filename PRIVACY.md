# Privacy Policy

Last updated: September 19, 2026

FocusLock is a Firefox extension designed to provide local browser focus and website-control functionality.

## Information Collection

FocusLock does not require an account.

FocusLock does not operate a remote server for collecting user information.

FocusLock does not intentionally collect personal information, browsing history, passwords, or the contents of webpages for transmission to the developer.

## Local Data

FocusLock may store extension settings and Focus Mode information using Firefox's extension storage facilities.

This may include information such as:

- Focus Mode settings
- Website rules
- Saved website sets
- Session state
- User interface preferences

This information is used to provide the extension's functionality.

## Website Access

FocusLock requires browser permissions necessary to implement website-control functionality.

Website access is used to determine whether a browser request or page is permitted according to the user's active Focus Mode configuration.

## Search Engines

If search-engine access is enabled by the user, searches are handled by the selected search engine in the normal way.

FocusLock does not operate the search engine or receive the user's search history through a FocusLock server.

## Third-Party Services

FocusLock does not include an analytics service, advertising service, or FocusLock-operated remote backend.

## Data Sharing

FocusLock does not intentionally sell, rent, or share user data with third parties.

## Changes to This Policy

If the extension's data practices change, this policy will be updated to describe those changes.

## Contact

For questions or privacy concerns, please use the contact or issue-reporting method provided in the project's public repository.
