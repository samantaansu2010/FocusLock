# FocusLock

FocusLock is a strict Firefox focus extension for timed, distraction-free browsing.

It lets you create focused browsing sessions where only the websites you explicitly allow are accessible.

## Features

- Timed Focus Mode
- Allow-only and block-list website policies
- Reusable saved website sets
- Search-engine access toggle
- Smart website syntax
- Automatic session expiration
- Persistent focus state
- Lightweight Firefox extension
- No account or external server required
